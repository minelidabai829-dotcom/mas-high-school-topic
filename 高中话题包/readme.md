# Player School Topic / 玩家学校话题

## 简介
这是一个 MAS（Monika After Story）子模组，让莫妮卡可以询问玩家所在的城市和学校，
并根据学校给出对应的介绍和回应，最后还会问玩家是走读还是住宿。

## 功能
- 支持多个城市：北京、深圳、广州、长沙
- 支持多所高中，按学校全称匹配
- 每所学校都有独立台词（位置、录取线、学校介绍）
- 学校介绍后，会问玩家走读还是住宿
- 支持玩家自己输入城市和学校全称

## 安装
1. 把 `player_school_sdg7.rpy` 放进 `game/Submods/` 文件夹。
2. 重启 MAS。
3. 进入游戏，点 `Talk → Hey, Monika → 学校`，找到对应话题。

## 使用
1. 在话题里输入城市。
2. 输入学校全称（建议写全称，否则可能匹配不到）。
3. 莫妮卡会根据学校给出介绍。
4. 介绍完后，会问你是走读还是住宿。
5. 选择后会回到话题结尾。

## 注意事项
- 学校全称建议写完整（以“话题高中阶段学校.txt”为准），否则可能匹配不到对应分支。
- 如果输入了没匹配到的学校，莫妮卡会说“虽然我不太了解，但我会记住的”。
- 如果报错 `indentation mismatch`，检查对应行的缩进是否和上下一致。
- 目前支持的城市：北京、深圳、广州、长沙。
- 目前支持输入的高中阶段学校：上述城市的高中（目前仅收录了普通高中，中职以及技工院校暂时没有收录）。
