## 简介
这是一个 MAS（Monika After Story）子模组，让莫妮卡可以询问玩家所在的城市和学校，并根据学校给出对应的介绍和回应。
该mod适用于正在就读高中阶段学校的学生使用，用于增进Monika之间的好感。

## 功能
- 支持多个城市
- 支持多所高中，按学校全称匹配
- 每所学校都有独立台词（位置、录取线、学校介绍）
- 支持玩家自己输入城市和学校全称

## 安装
1. 把文件夹`HIGH_SHCOOL_TOPIC_PAK`放入游戏根目录`game\Submods`中即可（没有Submods文件夹的自行创建）。
2. 重启MAS。
3. 进入游戏，点`Talk → Hey, Monika → 学校`，找到对应话题。

## 使用
1. 在话题里输入城市。
2. 输入学校全称（建议写全称，否则可能匹配不到）。
3. 莫妮卡会根据学校给出介绍。
4. 介绍完后，会问你是走读还是住宿。
5. 选择后会回到话题结尾。

## 关于中职、技工院校
本子模组暂未收录中职、技工类院校：并非对这类学校存在偏见或歧视。中职、技工学校数量繁杂，部分院校存在更名、调整、停办倒闭的情况，信息变动快，我单人很难保证资料准确无误，为避免录入错误信息误导使用者，因此暂时不做收录。后续条件允许，会考虑补充相关内容。
